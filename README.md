# 環球免費電視

Android TV 安裝檔下載。整合 TVB 免費區、ViuTV 99／96 官方播放頁，以及全球公開頻道搜尋、內置播放器和收藏。

TVB／ViuTV 的內容在 App 內以官方網站播放，並非合併其官方 App。香港直播受地區、登入及裝置相容限制；在目前的非香港測試網絡僅確認官方頁載入，尚未確認香港直播或 Panasonic 實機播放。全球目錄包含 10,134 個頻道及 179 個國家／地區，部分串流可能失效或限地區。

已在 Android TV 模擬器確認 APK 安裝、遙控選擇、NHK 與 DW 影音播放、全球搜尋及收藏保存。ARM 安裝檔支援 Android 8.0 或以上。

本專案不託管、轉播或解密電視內容。頻道名稱及內容屬於各自權利人。
